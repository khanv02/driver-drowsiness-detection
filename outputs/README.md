# Experiment outputs

<p><a href="README.vi.md">Tiếng Việt</a> | <strong>English</strong></p>

- `results/`: metrics, CSV tables, and evaluation results.
- `figures/`: plots and confusion matrices.
- `logs/`: run logs.

Git ignores generated output files; `.gitkeep`, `README.md`, and `README.vi.md` are retained. Experiment code is in `src/drowsyalert/experiments/`. Results selected for reports may be stored in `docs/` with configuration details and reproduction instructions.
