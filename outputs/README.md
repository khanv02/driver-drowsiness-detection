# Đầu ra thực nghiệm

- `results/`: metrics, bảng CSV và kết quả đánh giá.
- `figures/`: biểu đồ và confusion matrix.
- `logs/`: nhật ký chạy.

Các file đầu ra được bỏ qua bởi Git; `.gitkeep` và `README.md` được giữ. Mã chạy thực nghiệm nằm trong `src/drowsyalert/experiments/`. Kết quả chọn để đưa vào báo cáo có thể lưu trong `docs/`, kèm thông tin cấu hình và cách tái lập.
