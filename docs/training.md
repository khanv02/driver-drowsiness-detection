# EyeCNN training protocol

Status: the code path and synthetic smoke test are complete. Real CEW training is blocked
until T-075 verifies the owner-provided dataset. No real accuracy is currently claimed.

## Environment and inputs

Install the locked training dependencies:

```powershell
uv sync --extra train
```

The input must be a validated `manifest.csv` generated by the Phase 3 preparation command.
The loader rejects missing schema fields, invalid labels/hashes/splits, duplicate paths,
groups shared across splits, and splits without both classes. Record the manifest SHA-256
from `dataset.json` before training.

## Reproducible command

After T-075 confirms the actual CEW layout and the dataset has been prepared:

```powershell
uv run python scripts/train_model.py `
  --manifest data/processed/manifest.csv `
  --checkpoint models/checkpoints/eye_cnn.pt `
  --output outputs/results/eye_cnn-training `
  --epochs 30 `
  --batch-size 64 `
  --patience 5 `
  --learning-rate 0.001 `
  --seed 42 `
  --device auto
```

`models/checkpoints/` and `outputs/results/` are ignored artifact locations. Do not commit
the trained model or run output.

## Fixed model and preprocessing contract

- Classes: index 0 `open`, index 1 `closed`.
- Input: BGR eye patch resized to 64 x 64, converted to RGB CHW float32 in [0, 1].
- Network: three Conv/ReLU/MaxPool blocks (32, 64, 128 channels), adaptive average pool,
  dropout 0.3, and a two-logit linear classifier.
- Optimizer: Adam; loss: cross entropy.
- Train-only augmentation: brightness factor 0.8-1.2 and rotation -8 to +8 degrees.
- Seed controls Python, NumPy, Torch, the shuffled loader, and deterministic Torch algorithms.

## Selection rule and artifacts

Every epoch is measured on validation data. The checkpoint is replaced only when
validation macro F1 strictly improves; early stopping occurs after `patience` epochs without
improvement. Training never constructs or measures the test split.

- `run_config.json`: resolved inputs, manifest hash, seed, device, hyperparameters, sample
  counts, augmentation, and selection metric.
- `history.json`: train loss and validation Accuracy/macro F1 by epoch.
- `eye_cnn.pt`: architecture/preprocessing contract, state dictionary, manifest identity,
  seed, selected epoch, validation scores, and training settings.

The test split remains sealed until the checkpoint and inference threshold are frozen.
Held-out evaluation is a separate one-way command implemented under T-013. A successful
synthetic smoke run proves wiring and checkpoint compatibility only; it is not evidence of
model quality or real-world drowsiness performance.
