# EyeCNN training protocol

Status: CEW training and the single frozen held-out evaluation are complete. The image
classifier met the specified Accuracy target; this is not a video-level drowsiness result.

## Environment and inputs

Install the locked training dependencies:

```powershell
uv sync --extra train
```

The input must be a validated `manifest.csv` generated by the Phase 3 preparation command.
The loader rejects missing schema fields, invalid labels/hashes/splits, duplicate paths,
groups shared across splits, and splits without both classes. Record the manifest SHA-256
from `dataset.json` before training.

## Reproducible command

Final training command:

```powershell
uv run python scripts/train_model.py `
  --manifest data/processed/manifest.csv `
  --checkpoint models/checkpoints/eye_cnn_50.pt `
  --output outputs/results/eye_cnn-training-50 `
  --epochs 50 `
  --batch-size 64 `
  --patience 5 `
  --learning-rate 0.001 `
  --seed 42 `
  --device cpu
```

`models/checkpoints/` and `outputs/results/` are ignored artifact locations. Do not commit
the trained model or run output.

## Fixed model and preprocessing contract

- Classes: index 0 `open`, index 1 `closed`.
- Input: BGR eye patch resized to 64 x 64, converted to RGB CHW float32 in [0, 1].
- Network: three Conv/ReLU/MaxPool blocks (32, 64, 128 channels), adaptive average pool,
  dropout 0.3, and a two-logit linear classifier.
- Optimizer: Adam; loss: cross entropy.
- Train-only augmentation: brightness factor 0.8-1.2 and rotation -8 to +8 degrees.
- Seed controls Python, NumPy, Torch, the shuffled loader, and deterministic Torch algorithms.

## Selection rule and artifacts

Every epoch is measured on validation data. The checkpoint is replaced only when
validation macro F1 strictly improves; early stopping occurs after `patience` epochs without
improvement. Training never constructs or measures the test split.

- `run_config.json`: resolved inputs, manifest hash, seed, device, hyperparameters, sample
  counts, augmentation, and selection metric.
- `history.json`: train loss and validation Accuracy/macro F1 by epoch.
- `eye_cnn.pt`: architecture/preprocessing contract, state dictionary, manifest identity,
  seed, selected epoch, validation scores, and training settings.

The test split remains sealed until the checkpoint and inference threshold are frozen.
After that freeze, run the held-out evaluation once into a new result directory:

```powershell
uv run python scripts/evaluate_model.py `
  --manifest data/processed/manifest.csv `
  --checkpoint models/checkpoints/eye_cnn.pt `
  --output outputs/results/eye_cnn-heldout `
  --threshold 0.5 `
  --device auto
```

The evaluator verifies that the checkpoint was validation-selected from the exact manifest,
records checkpoint/manifest hashes, counts, Accuracy, confusion matrix, per-class
Precision/Recall/F1, macro F1, and whether Accuracy >= 0.90. It refuses to overwrite an
existing `metrics.json`. A successful synthetic smoke run proves wiring and checkpoint
compatibility only; it is not evidence of model quality or real-world drowsiness performance.

## Runtime confidence policy

CNN inference is recorded as source `cnn_eye_classifier`; it never replaces the
`landmark_ear` identity. Each valid eye produces an independent closed probability. With
the default `cnn_threshold: 0.5` and `cnn_uncertainty_margin: 0.1`, probabilities at or
below 0.4 are confidently open, probabilities at or above 0.6 are confidently closed, and
values between those bounds are unknown. One confidently open eye establishes an open
observation; closed requires two confidently closed eyes. Uncertain or unilateral-closed
evidence remains unknown.

Every runtime summary and CSV row records the source, threshold, uncertainty margin, and
checkpoint SHA-256. Missing or incompatible checkpoints fail explicitly; the application
does not fall back to EAR while claiming CNN evidence.
