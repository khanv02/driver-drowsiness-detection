# Tài nguyên mô hình

<p><a href="README.md">English</a> | <strong>Tiếng Việt</strong></p>

- `pretrained/`: model tải sẵn, ví dụ Face Landmarker.
- `checkpoints/`: trọng số CNN cùng metadata huấn luyện.
- `exported/`: model xuất để suy luận.

File tài nguyên trong thư mục này được bỏ qua bởi Git; `.gitkeep`, `README.md` và `README.vi.md` vẫn được giữ. Mã định nghĩa CNN nằm trong `src/drowsyalert/models/`. Hiện chưa có model tải về hoặc checkpoint đã huấn luyện.
